## 📌 Sobre o Projeto

Este repositório foi desenvolvido para fins estritamente educacionais como parte do desafio final de sprint do semestre. 

O **PIT WALL** é uma aplicação web projetada para o universo do automobilismo, oferecendo uma interface interativa para fãs do esporte. A plataforma simula(com dados fictícios) e organiza as seguintes funcionalidades:
- **Venda de Ingressos:** Área dedicada para a escolha e compra (simulada) de ingressos para as corridas.
- **Grid de Pilotos:** Apresentação visual e detalhada de todos os pilotos que compõem o grid.
- **Classificação:** Tabela com o ranking, mostrando a pontuação e posição de cada piloto (dados fictícios).

A interface permite visualizar todo o conteúdo de forma imersiva, responsiva e estruturada.
